# 🌱 BioZabb Flashcards - Q&A Pitching Trainer

ระบบ Flashcard ซ้อมตอบคำถามสำหรับ Pitching และการตอบคำถามกรรมการ โปรเจกต์ **BioZabb** (ผงปรุงรสธรรมชาติ 100% จากผักเหลือทิ้งผ่านการหมักธรรมชาติ)

🌐 **เข้าใช้งานออนไลน์ผ่าน GitHub Pages:**
👉 [https://punnawitsunarat.github.io/Biozabb/](https://punnawitsunarat.github.io/Biozabb/)

---

## ✨ ฟังก์ชันเด่น (Features)

1. **โหมดฝึกซ้อม 2 รูปแบบ (Dual Modes)**:
   - **🃏 Flashcard View**: ซ้อมตอบทีละข้อด้วยการ์ด 3D Flip (คลิกหรือแตะที่ตัวการ์ดเพื่อสลับคำถาม-คำตอบ)
   - **📋 List View**: แสดงคำถามทั้งหมดเป็น 2 คอลัมน์คู่ขนาน (คำถามทั่วไป vs คำถามเจาะลึก) แตะที่แถบเพื่อคลี่ดูคำตอบรายข้อ
2. **ระบบแบ่งหมวดหมู่ชัดเจน**:
   - 🌿 **หมวดคำถามทั่วไป (9 ข้อ)**
   - 🔬 **หมวดคำถามเจาะลึกโปรเจกต์ (12 ข้อ)**
   - ⭐ **หมวดที่ต้องทบทวน (Starred)**
3. **ฟังก์ชันช่วยจำระดับโปร**:
   - 🔊 **Text-to-Speech (TTS)**: ฟังเสียงอ่านคำตอบภาษาอังกฤษ พร้อมปรับความเร็วได้ (0.8x / 1.0x / 1.2x)
   - 🔍 **Real-time Search**: ค้นหาคำสำคัญได้ทั้งภาษาไทยและอังกฤษ
   - 🔀 **Shuffle**: สุ่มคำถามเพื่อจำแบบไม่เรียงลำดับ
   - ⌨️ **Keyboard Shortcuts**: รองรับ Spacebar, ลูกศรซ้าย/ขวา, S, B, P

## 🛠️ โครงสร้างไฟล์ (Project Structure)

- `index.html` — โครงสร้างหน้าเว็บ แถบควบคุม Flashcard และ 2-Column List
- `style.css` — ธีม Modern Organic Glassmorphic และ Responsive Layout
- `cards-data.js` — ฐานข้อมูลคำถาม-คำตอบทั้ง 21 ข้อ
- `app.js` — ควบคุมการทำงานทั้งหมด (Flip, TTS, Search, Filter, LocalStorage)
